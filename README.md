
# Electric Field Change Measurements and Lightning Observations

This repository contains circuit designs and software developed for research involving slow antennas and optical verification of long continuing current (LCC) lightning. Additionally, designs for a novel diametrically loaded loop antenna for lightning research and an Active Bias Integrator (ABI) charge amplifier for slow antenna applications are presented. Much of this work is described in the Author's Master's Thesis 'DESIGN AND IMPLEMENTATION OF A SLOW ANTENNA FOR OBSERVING LONG CONTINUING CURRENT LIGHTNING'


## Repository Contents

- **ABI Charge Amplifier Circuit** – Active Bias Integrator (ABI) charge amplifier design (adapted from Alnasser).
  - **Contents:** KiCad circuit design files.

- **BAS_CAM Code** – Basler camera acquisition software.
  - **Contents:** C++ code and Makefile for Basler camera operation.

- **DAQ Code** – Data acquisition software for recording slow antenna measurements.
  - **Contents:** Python code and environment for the MCC 128 DAQ on Raspberry Pi 4.

- **Diametric Loaded Loop Circuit** – Circuit design and simulations for a diametrically loaded loop antenna (adapted from Kanda).
  - **Contents:** KiCad circuit design files.

- **PI_CAM_code** – Raspberry Pi camera acquisition software.
  - **Contents:** Raspberry Pi camera code for automatic continuous recording upon startup or reboot.

- **Slow Antenna Circuit** – Conventional slow antenna charge amplifier circuit design and simulations.
